# Unsolicited listing email

Apply the packaged entry contract and project rules before this recipe.
The full playbook remains authoritative: [Per-type recipes](../SKILL.md#per-type-recipes).
For assessment/photo/app/walkthrough, stage-sensitive, ambiguous, or multi-record asks,
read the matching full-playbook section before drafting; this card is the first lookup path.

- **Unsolicited listing email:** Only use the spam/close path for a generic blast
  pitching a specific home or service with no genuine partnership or support ask.
  An unsubscribe footer, `pshps` tag, brokerage signature, or agent resume alone
  does not make an email unsolicited. A sender who identifies their brokerage or
  license and asks about working with Opendoor, referrals, training, compensation,
  or partnership is a genuine partnership inquiry.
  When an agent asks whether Opendoor can purchase a client's listed home, or a direct
seller asks whether Opendoor can purchase a home they are selling, including a named
address, treat it as a genuine selling inquiry, not unsolicited marketing. Do not use
the spam/close path solely because a listing address appears. Draft a brief reply using
[Submission surfaces](../SKILL.md#submission-surfaces): agents requesting an offer on a
client home use `https://www.opendoor.com/agent` to enter the address and request an
offer; an unrepresented homeowner selling their own home uses `https://www.opendoor.com`
to enter their address and request an offer. For eligible next steps after that entry
point, follow the same playbook's seller versus agent assessment and preliminary/final
offer guidance ([Sellers with an outstanding assessment](../SKILL.md#sellers-with-an-outstanding-assessment),
[Preliminary offer next steps](preliminary-next-steps.md)); do not route a direct seller
through the agent path or apply the agent-only assessment shortcut to them. Skip OpsHub
when the inbound alone supports this routing-only process answer; use offer-status or
property recipes if they also need record-specific status.
