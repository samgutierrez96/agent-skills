# Seller says they are working with an agent or asks whether the agent can meet instead

Apply the packaged entry contract and project rules before this recipe.
The full playbook remains authoritative: [Agents vs sellers](../SKILL.md#agents-vs-sellers).
For assessment/photo/app/walkthrough, stage-sensitive, ambiguous, or multi-record asks,
read the matching full-playbook section before drafting; this card is the first lookup path.

- **Seller says they are working with an agent or asks whether the agent can meet
  instead:** first collect the agent's full name and email address so the agent
  can be added to the property and the listing agreement can be respected. Check
  the existing agent/customer record for remaining details and collect them from
  the agent only if needed. Do not route this as a
  direct-seller assessment request before collecting agent information.
  This includes a spouse or co-owner identified as the listing agent. Verify that
  named person's details; the requester's own contact information does not identify
  a different agent. If the agent's full name/email are still missing, ask for them
  so their role can be included. A later assessment confirmation or reminder does
  not resolve this agent-role detail. Do not replace that ask with a visit recap,
  collect access-verification credentials without an access ask, or claim the agent
  has been added without a verified action.
