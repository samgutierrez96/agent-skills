# Buyer condition, systems, or layout question

Apply AGENTS.md and the packaged entry contract. This card carries the existing
`Per-type recipes` condition/systems stop rule. Read [Public listings](../SKILL.md#public-listings)
by exact heading when not loaded. For an exception not covered here, read only the
matching per-type passage; do not search repeatedly through the entire playbook.

1. Verify ticket/requester/channel/newest question and each requested detail.
   Preserve the required same-concern resolution check on record-specific asks.
   If a verified later resolution answers it, stop with the required no-reply note.
2. Make one exact address match with `list_properties` or `pds_search_by_address`
   (use `opendoor_owned: true` when applicable). Preserve the existing one normalized
   retry budget when no usable positive match is returned. Do not guess identifiers.
3. Use an exact Opendoor listing URL returned by the connector. If absent, allow
   at most one focused public Opendoor search for the full address. Fetch only the
   exact matched property. An unrelated home's similar-listing mention is not a
   match. No repeated search variants, browser discovery, shell fetch workarounds,
   or extra `get_property` read solely to chase a public URL.
4. Answer from retrieved facts only. Never infer wiring, upgrades, water history,
   room adjacency, separate entrances or basement status from missing data or
   photos. Point at verified photos/labeled floor plans; mention a seller's
   disclosure only when the retrieved page actually shows its download. Answer
   every specific question or state which detail cannot be confirmed.
5. If the exact page or requested detail remains unavailable, stop. State that the
   detail cannot be confirmed; explain that the customer may complete an independent
   inspection if they place an offer. Put the retrieval gap in the operator appendix.
   Do not invent a disclosure request, attachment, completion or delivery timeline.

A separate touring/access, assessment, stage or identity question keeps its required
gates. A public-information-only answer does not need trust or access research to
fill an appendix. Use two non-empty copy boxes; no internal discrepancies outward.
