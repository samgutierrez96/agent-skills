# Touring/access

Apply the packaged entry contract and project rules before this recipe.
The full playbook remains authoritative: [Access codes](../SKILL.md#access-codes); [Trust level](../SKILL.md#trust-level).
For assessment/photo/app/walkthrough, stage-sensitive, ambiguous, or multi-record asks,
read the matching full-playbook section before drafting; this card is the first lookup path.

- First follow [resolution-first access](access-resolution.md). Stop if recent
  notes confirm this request was already resolved. Otherwise continue below.
- **Unresolved touring/access:** Zendesk MCP → property listing stage. Under contract means
  no viewing, including an agent preview for a backup offer; stop scheduling
  guidance there. Do not send the requester to phone support, an app, or a showing
  service to schedule that viewing. Older tours-until-closing guidance and a
  system allowing booking do not override this gate.
- When the listing stage permits viewing: customer lookup → property Flags. Never provide a
  code or remote unlock when trust is denied.
