# Showami assessment access when seller will be absent

Apply the packaged entry contract and project rules before this recipe.
The full playbook remains authoritative: [Access codes](../SKILL.md#access-codes); [Sellers with an outstanding assessment](../SKILL.md#sellers-with-an-outstanding-assessment).
For assessment/photo/app/walkthrough, stage-sensitive, ambiguous, or multi-record asks,
read the matching full-playbook section before drafting; this card is the first lookup path.

- **Showami assessment access when seller will be absent:** confirm the home will
  be vacant. If vacant, ask the seller to provide the access code to Opendoor so
  it can be given to the Showami representative; do not tell the seller to send
  it directly to the assessor. This exception overrides the generic buyer-tour
  access-code path.
