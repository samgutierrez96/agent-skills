# Preliminary offer next steps

Apply the packaged entry contract and project rules before this recipe.
The full playbook remains authoritative: [Sellers with an outstanding assessment](../SKILL.md#sellers-with-an-outstanding-assessment).
For assessment/photo/app/walkthrough, stage-sensitive, ambiguous, or multi-record asks,
read the matching full-playbook section before drafting; this card is the first lookup path.

- **Preliminary offer next steps:** The dashboard displays the next-step
  instructions; the assessment is not completed inside the dashboard. A direct
  seller can complete it through the **Opendoor Key App** or schedule an
  in-home walkthrough. The agent-only Key App restriction is an internal
  routing rule and should not be mentioned to a seller unless the ticket
  identifies the customer as an agent.
